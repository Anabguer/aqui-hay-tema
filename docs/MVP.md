# Alcance de prototipo (ya no «MVP de 30 días»)

El bloque «MVP PROPUESTO» del Maestro era una **primera** cesta. La **V0 jugable** está aprobada; aún no se programa. Fichas: `FASE_DISENO_POOL_16.md`. Primero **2–3 pilotos**. Nadie final sin `CHECKLIST_AUDITORIA_PERSONAJES.md`.

## Sigue teniendo sentido

Probar si engancha **antes** de 200 ilustraciones. Tarjetas feas valen si el pueblo vive, hay pistas, hay presión y hay humor.

## Lo que ya no se da por bueno

| Antes | Ahora |
| --- | --- |
| 30 días de partida | Pueblo persistente + temporadas (días por temporada: no cifrados) |
| 8 lugares todos disponibles | 3 abiertos + 3 candados visibles (cine, bar, arcade) |
| 10 eventos de pareja / 5 globales | Candidatos; recorte después |
| Población 10 al día 1 / techo 14 | ~3 al inicio · Bloque A ~16 · pool = tandas |
| Derrota / «X parejas = ganas» | Sandbox + rótulo por bloque / comunidad |
| Personaje inerte | Vida sencilla + diario |
| Sin economía | Dinero + fama (sin cifras) |
| Ropa en el primer prototipo | Modelo sí, tienda no |

## Qué tiene que poder verse en un prototipo feo (cuando toque programar)

- Mapa: 3 abiertos + 3 🔒
- **El pueblo**: tarjetas de habitantes
- Dinero y fama visibles (aunque la economía sea dummy)
- Diario corto + coletillas
- Cita o plan de amistad: dos personas, lugar abierto, franja; tope de encuentros a revisar
- Test de compatibilidad cutre, sin %
- Parejas y amistades con estado legible, no un % 
- Algún NPC que se mueva / coincida sin el jugador
- Una llegada-acontecimiento
- Placeholders de caricatura, no fotos

# Ropa y looks

**V0 jugable:** ni tienda, ni compra, ni selección de look. Cabeza maestra (cuando se apruebe estilo) + placeholder.

**Modelo de ficha (ya):** `estilo_visual`, `rasgos_fisicos`, `etiquetas_look_base`, `looks_posibles`, `preferencias_esteticas`.

## Cabeza maestra + cuerpo (futuro)

```text
IDENTIDAD VISUAL = CABEZA MAESTRA + LOOK/CUERPO
```

La cara/pelo/gafas no se redibujan por cada outfit. El cuerpo/ropa se estudia después. No se genera ni se programa ahora. Detalle de encuadre: `CONTRATO_VISUAL_PERSONAJES.md`.

Looks previstos (nombres, no assets): cotidiana, cita, elegante, fiesta, cómoda, evento.

## Modificadores, no la mejor ropa

No existe el look ganador del juego.

Un look empuja **probabilidades** (+ / 0 / −) según:

- quién lo lleva
- si le da seguridad o le disfraza
- quién tiene delante
- preferencias de esa persona (a menudo **ocultas** al inicio)
- lugar
- actividad
- tipo de cita

Una cita «bien vestida» puede salir regular. Encaje: `PREPARACION_DE_CITAS.md`.

El jugador descubre preferencias estéticas; no las tiene en un menú el día 1.

«Lo ideal para impresionar» puede hacer que quien se viste se sienta fatal — se mantiene del Maestro.

## Desbloqueo

Looks con dinero, fama u hitos. Costes no fijados. Fuera de la implementación inmediata.

# Preparación de citas (sistema candidato)

**No es implementación. No hay fórmulas. No entra en la V0 programable todavía.**

Idea: en citas importantes el jugador puede **preparar** la experiencia. Cada elección modifica **probabilidades**, no garantiza el resultado.

No queremos:

```text
80 puntos = cita perfecta
```

Queremos:

```text
las decisiones empujan; las personas y el azar siguen mandando
```

Una cita muy bien preparada puede salir regular. Una mediocre puede conectar. Si no, dejan de parecer personas.

---

## Qué se puede preparar (lista abierta)

| Factor | Notas |
| --- | --- |
| Pareja | Ya es la decisión central |
| Lugar | Solo sitios desbloqueados. **Aforo + horario** deben caber o no se confirma. |
| Hora / franja | Encaje con rutinas |
| Actividad | Si el sitio la tiene |
| Ropa / look | **Después**; ver `ROPA_Y_LOOKS.md`. No en V0 |
| Música | Si el lugar/actividad lo admite |
| Ambiente | Luz, ruido, intimidad… cuando exista |
| Comida / bebida | Si toca (cafetería, restaurante futuro…) |
| Decisiones en la cita | Micros; el jugador no puppetea el diálogo entero |
| Estado previo | Ánimo, cansancio, flag `nuevo` |
| Historia de la relación | Las 4 variables + recuerdos |

Cada factor puede ser **+ / 0 / −** según **las dos** personas, no según un look universal.

Siguen pesando: personalidad, química (asimétrica), historial, ánimo, azar controlado.

---

## Información incompleta

El jugador **no** conoce de entrada todos los gustos ocultos.

Preparar una cita es también **aprender** el pueblo.

- Si ya descubriste que a alguien le va cierto tipo de música, puedes usarlo.
- Si no lo sabes, decides a ciegas (o con rumor 👀).

Los gustos descubiertos son **información útil**, no adorno de ficha. Encaja con diario 👀 / ⚠️ y con «el jugador no ve el Excel interno».

Si un gusto **cambia** por una experiencia (`APRENDIZAJE_PREFERENCIAS.md`), lo descubierto puede quedar desfasado: el jugador se entera por una pista, no por un recálculo en pantalla.

No spoilear la ficha A en la UI de preparación.

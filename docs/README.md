## Autoridad

1. `DECISIONES_CERRADAS.md` gana al Maestro en los puntos que lista.
2. El resto del Maestro sigue vigente.
3. La PNG no gana a las decisiones de mapa bloqueado ni a las variables internas.
4. Lo ambiguo va a pendientes, no se cierra aquí.
5. Una ficha no es final sin `CHECKLIST_AUDITORIA_PERSONAJES.md`.

## Cafetería — qué cambia

- **A** maqueta juguete, poco detalle, toldo liso, formas gordas.
- **B** pueblo: toldo de rayas, terraza, escaparate con luz. La más cercana al tablero de Carlos II.
- **C** papel recortado, bordes imperfectos, más cutrez.
- **D** más dibujada, más volumen y cartel. Riesgo: pasarse de detalle respecto a las caras.

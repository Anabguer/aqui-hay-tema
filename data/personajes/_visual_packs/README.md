# Packs visuales (consumo del motor)

El motor **no crea** imágenes. Lee este registro y sirve PNG que ya existen y están versionados.

```text
visual_identity_version  = identidad de la cabeza maestra
expresion.identidad_version debe coincidir o el asset se ignora
neutral                  = obligatorio
resto                    = progresivo
```

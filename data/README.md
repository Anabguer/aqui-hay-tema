# Datos previstos

Catálogos de referencia + plantilla de personaje. Las 16 fichas siguen vacías hasta que se rellenen con el marco de diseño.

```text
data/
  catalogos/
    profesiones.json
    parentescos_veto_romance.json
    tipos_relacion_social.json
    orientaciones.json            (mujer / hombre / no_binarie)
    franjas_disponibilidad.json
    rasgos.json                   (10 candidatos V0)
    aficiones.json                (12 candidatos V0)
    hobbies_lugares.json
    estilos_sociales.json
    etiquetas_look.json
    ejes_preferencia.json         (aprendizaje de gustos; candidatos)
    preferencias.json             (prosa; lista cerrada PENDIENTE)
  lugares/lugares.json            (14 sitios; mapa V0: 3 + 3 candados)
  personajes/                     _plantilla.personaje.json (canónica) + retrato + lista vacía
  relaciones/                     romántica (4 vars) + social
  diario/                         plantilla Diario del pueblo
  jugador/                        temporada + 3 lugares abiertos
```

Cómo rellenar personajes: `docs/FASE_DISENO_POOL_16.md` + `docs/CONTRATO_PERSONAJE.md`. Retratos: `docs/CONTRATO_VISUAL_PERSONAJES.md`. Auditoría: `docs/CHECKLIST_AUDITORIA_PERSONAJES.md`.

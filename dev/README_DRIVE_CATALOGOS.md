# Catálogos candidatos — Aquí Hay Tema

**Abrir primero:** `LAB_CATALOGOS_PERSONALIDAD.md`

Luego, si quieres ver personas concretas: `MUESTRA_20_CATALOGOS.md`

Los JSON de la carpeta `json/` son **candidatos**. No son producción. No sustituyen P001–P200.

## Qué está aprobado

- Taxonomía: aficiones, gustos, rechazos, rasgos, preferencias sociales por ejes, `afecto_estilo`, manías narrativas.
- `afecto_estilo` = identidad individual (cómo tiende a vincularse). No es Relacional V1.
- Cardinalidad de dirección: 3 aficiones + 3 rasgos canónicos. Al llegar se conoce 1+1. El resto se descubre.

# Prueba — suelo ilustrado (una sola)

Carlos II. Tras rechazo del acabado con carreteras geométricas/SVG.

## Pregunta de aprobación

Si quitamos la cafetería, ¿este trozo de mapa parece pertenecer visualmente a la misma ilustración que ella?

## Qué hay

1. 	rozo_sin_cafe.png — pueblo dibujado solo (carretera ilustrada, manzana vacía, parque, detalles)
2. 	rozo_con_cafe.png — misma ilustración + cafetería C3 real (sin modificar)
3. comparacion_sin_vs_con.png — lado a lado
4. detalle_cafe_sobre_suelo.png — zoom

## Reglas respetadas

- Dimensionar desde el tamaño real del edificio
- Espacio de crecimiento en la manzana (continuo, sin caja de layout)
- Carretera fina dibujada (no rectángulo SVG)
- Parque ilustrado
- Vista frontal/plana de tablero
- Lenguaje cómic limpio alineado con referencia + C3
